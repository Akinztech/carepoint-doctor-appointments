Doctor appointment management

A clearer path to better care.

CarePoint is a local-first demonstration app for requesting appointments and managing care journeys, built for patients, doctors, and administrators.

Explore the project Run it locally

Care coordination, in one place.

Explore a responsive interface and a lightweight backend designed to make common appointment workflows easy to understand.

For patients

Find doctors, request a suitable time, and review or cancel appointments.

For doctors

Manage availability and review, confirm, or complete patient requests.

For administrators

Oversee appointment status and manage doctor profiles from one workflow.

This GitHub Pages site is a static project overview. The working appointment application uses a Python and SQLite backend that must be run locally or deployed to a separate server.
CarePoint is an educational demonstration, not a clinical or production-ready health service.
